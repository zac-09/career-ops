Mitigation: a small public repo (Express + Postgres + Redis cache, Dockerised) would turn this into "learning in public". It's worth building because Postgres keeps recurring across the pipeline.
2. **Automated testing.** There is no evidence. Don't claim a test discipline. If asked, describe how the migration was verified (shadow traffic, rollback per service) and say plainly that a formal test pyramid is something he'd adopt, not something he brings.
3. **CI/CD and GitLab.** Nice-to-have only. Mention Docker/K8s deployments and leave it there.
4. **Formal code review.** Frame the CodeBits lead role and the MTailor documentation and training as mentoring. Don't invent a PR-review process.
