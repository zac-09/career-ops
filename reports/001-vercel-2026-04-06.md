- **JD Level:** Mid-Senior Software Engineer (5+ YoE, IC role)
- **Isaac's Level:** Mid-level Backend Engineer with cloud migration expertise

### Assessment
This role is **not a fit** for several reasons:

1. **Golang is a hard requirement** — The JD explicitly states "Proficiency in Golang". Isaac lists Go as "Intermediate" but has no production Go experience in his CV.

2. **Domain mismatch** — CDN/edge infrastructure is a specialized domain requiring deep knowledge of:
   - Load balancing and traffic routing
   - TLS termination at scale
   - Caching strategies and cache invalidation
   - Network protocols (BGP, DNS, TCP optimization)
   - Edge computing patterns

   Isaac's experience is in application-layer backend development, not network infrastructure.

3. **Location constraints** — The hybrid requirement (Mon/Tue/Fri in SF/NYC) likely means they prefer local candidates. While it says "fully remote for others," Vercel may prioritize hybrid candidates for a core infrastructure team.

### Recommendation
**DO NOT APPLY.** The Golang requirement alone is disqualifying. Spending time on this application would yield no return. Focus on roles matching Isaac's Node.js/Firebase/GCP strengths.
